Как начать работу

Выберите категорию и конфигурацию, затем нажмите главную кнопку запуска. Проверьте нужный сайт или игру. Если профиль не подходит, попробуйте другой профиль этой категории. Для работы движка Windows запрашивает права администратора.

Сборка 0.3.5.70 включает .NET 10 в установщик. Отдельная установка .NET не требуется. Доступ к стороннему сервису может зависеть от провайдера, региона, DNS и ограничений самого сервиса.

«Движок завершился сразу после запуска»

Посмотрите журнал событий и результат диагностики в настройках. Закройте другие лаунчеры zapret, которые могут использовать winws. Если ошибка появилась после добавления своего профиля, проверьте его конфигурацию или отключите этот профиль. Не отключайте защиту Windows для диагностики: при блокировке сохраните точный текст уведомления и отправьте его в поддержку.

«A copy of winws is already running»

Завершите другую копию ZAPRET CONTROL или лаунчер, использующий winws, и повторите запуск. Если процесс остался после сбоя и его источник непонятен, перезагрузите Windows.

Обновление и удаление

Перед обновлением выберите «Выход» в трее, затем запустите новый установщик. Для удаления используйте «Параметры Windows → Приложения → Установленные приложения → ZAPRET CONTROL → Удалить».

В новых версиях консоль удаления скрыта. Возможен запрос прав Windows. Если файл драйвера занят, программа может сообщить о необходимости перезагрузки для завершения удаления.

Настройки и лицензия сохраняются для переустановки. Порядок полного удаления данных описан в политике конфиденциальности.

Свои сервисы и Pro

«Свои сервисы» доступны с действующим Pro-ключом. Обычный пользовательский ключ привязан к одному компьютеру; обычная переустановка приложения на той же Windows обычно сохраняет код устройства. Переустановка самой Windows или изменение её идентификатора может потребовать восстановления через поддержку.

Продажи Pro пока не открыты. Донат через «Поддержать автора» сам по себе не выдаёт и не активирует Pro. Полный ключ или токен заказа в публичных обращениях не размещайте.
