Политика конфиденциальности

Редакция от 17 ноября 2026 года · приложение ZAPRET CONTROL 0.3.5.70 и сайт поддержки

Разработчик ZAPRET CONTROL — shiroglazov. По вопросам обработки данных и удаления сведений обращайтесь на grokgpt1977@gmail.com. Эта политика описывает приложение для Windows и страницы поддержки проекта.

1. Какие данные используются

  • Настройки: выбранные профили, параметры запуска, звука и трея, состояние знакомства с приложением и идентификатор установки.
  • Свои сервисы: названия профилей, домены и конфигурации, которые вы добавляете или импортируете.
  • Pro: лицензионный ключ и код компьютера для привязки доступа к одному устройству. Код вычисляется локально как SHA‑256 от идентификатора Windows MachineGuid и префикса приложения. Исходный MachineGuid не отправляется механизмом проверки заказа. Хэш позволяет узнавать устройство, поэтому мы не считаем его анонимными данными.
  • Диагностика: сведения о наличии файлов движка, доменах проверяемых сервисов, результатах DNS/сетевых проверок и технических ошибках.

2. Хранение на компьютере

Настройки, ключ и резервные копии своих профилей хранятся в %LOCALAPPDATA%\ZapretControl. Рабочие конфигурации и списки находятся также в папке Runtime рядом с приложением; временные конфигурации сеанса — в %TEMP%\ZapretControl. Журнал событий отображается в приложении; установщик может записывать технический журнал %TEMP%\ZapretControl-Setup.log или по пути, заданному пользователем.

В проверенном коде приложения нет рекламных трекеров, отдельной системы аналитики и автоматической отправки разработчику журнала событий, истории посещений или содержимого переписки.

3. Сетевые запросы и работа движка

Приложение запускает локальный движок zapret с драйвером WinDivert. Движок обрабатывает сетевые пакеты на компьютере согласно выбранным конфигурациям. Трафик не направляется через сервер разработчика как через VPN; приложение не обещает смену IP-адреса или анонимность.

При запуске диагностики или проверок доступности могут выполняться DNS-запросы и обращения к проверяемым сайтам, например YouTube и Discord. DNS-провайдеры и сайты при этом получают обычные для такого обращения сетевые данные, включая IP-адрес. Собственные и импортированные конфигурации могут менять набор адресов и правил обработки трафика.

4. Активация и проверка Pro

Проверка вручную введённого лицензионного ключа выполняется локально. Обычные пользовательские ключи привязаны к устройству. Для сертификации могут предоставляться временные проверочные лицензии без привязки к компьютеру; их подпись и срок действия также проверяются локально. Код компьютера копируется в буфер обмена по нажатию соответствующей кнопки; он не отправляется разработчику автоматически.

Если настроен сервер лицензирования и вы нажимаете «Проверить заказ», приложение отправляет на него номер/токен заказа и хэш кода компьютера через HTTPS. Цель — проверить заказ, выдать ключ и привязать его к устройству. Сервер и его хостинг получают также технические данные соединения, например IP-адрес. В сборке 0.3.5.70 адрес сервера не задан: эта проверка не выполняет запрос до настройки сервера. Публичные продажи Pro пока не открыты.

Перед запуском продаж и сервера сведения об операторе сервера, хостинге и сроках хранения заказов будут уточнены в политике. Здесь не заявляется, что такой сервер уже работает.

5. Поддержка и сторонние сайты

Если вы обращаетесь по почте, разработчик получает адрес отправителя, содержание сообщения и добровольно приложенные файлы. Они используются для ответа и решения проблемы, не продаются и не используются для рекламы. Переписка хранится на время решения обращения и последующей связи по нему; запросить удаление можно по адресу выше, с учётом применимых обязанностей хранения. Не присылайте пароли, данные банковских карт и полный Pro-ключ.

Обращения в GitHub Issues общедоступны. Для личных данных используйте почту. GitHub обрабатывает данные аккаунта и публикаций по своей политике конфиденциальности.

Кнопка «Поддержать автора» открывает CloudTips в браузере. Платёжные данные обрабатывает платёжный сервис по своим условиям; приложение не запрашивает реквизиты карты. Открываемые сторонние сайты действуют по собственным политикам.

6. Эти веб-страницы

На страницах проекта нет форм ввода, сторонних скриптов аналитики, собственных cookies или хранилища localStorage. Сайт размещён на GitHub Pages. GitHub сообщает, что регистрирует IP-адреса посетителей Pages для безопасности независимо от входа в аккаунт; подробности — в документации GitHub Pages.

7. Удаление данных и ваши обращения

Свои профили можно удалять в приложении. Удаление программы сохраняет локальные настройки и лицензию для возможной переустановки. Для полного удаления локальных данных завершите приложение, при необходимости сохраните ключ и нужные конфигурации, удалите программу и затем папку %LOCALAPPDATA%\ZapretControl. Временные файлы и журнал установщика можно удалить отдельно. Это не удаляет сведения о заказе на сервере или переписку.

Чтобы запросить сведения, исправление или удаление данных, переданных разработчику, напишите на grokgpt1977@gmail.com. Достаточно описать обращение; отправлять пароль, реквизиты карты или полную лицензию не нужно. Для проверки запроса может потребоваться подтверждение, что он относится к вам.
