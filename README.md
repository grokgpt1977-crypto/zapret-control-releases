# ZAPRET CONTROL

Приложение для управления конфигурациями движка zapret в Windows. Разработчик — **shiroglazov**.

## Скачать

Установщики публикуются в разделе [Releases](https://github.com/grokgpt1977-crypto/zapret-control-releases/releases). Выберите выпуск и скачайте приложенный `ZAPRET_CONTROL_<версия>_Setup.exe`.

**Готовится выпуск 0.3.5.74.** Пока установщики в Releases не опубликованы.

Автоматические архивы GitHub «Source code» содержат файлы этого репозитория и не являются установщиками приложения.

## Установка

Завершите ZAPRET CONTROL через «Выход» в трее, затем запустите установщик. В сборке 0.3.5.74 среда .NET 10 включена в пакет: отдельно скачивать её не требуется. Для работы движка Windows может запросить права администратора.

Для 0.3.5.74 доступна тихая установка:

```powershell
.\ZAPRET_CONTROL_<версия>_Setup.exe /quiet
```

Параметр `/quiet` относится к установке, а не к запуску приложения. По завершении установка не запускает приложение автоматически.

## Проверка файла

Вместе с установщиком публикуется `SHA256SUMS.txt`. Рассчитайте хэш скачанного файла и сравните его со значением в выпуске:

```powershell
Get-FileHash .\ZAPRET_CONTROL_<версия>_Setup.exe -Algorithm SHA256
```
