ZAPRET CONTROL — приложение для Windows x64 для управления конфигурациями zapret.

### В версии 0.3.5.74

- .NET 10 включён в установщик.
- Тихая установка `/quiet`, без автоматического запуска приложения.
- Подготовлена покупка Pro за 250 ₽ разово: СБП выбран первым, также доступна карта.
- Серверная интеграция ЮKassa проверяет оплату через API перед выдачей подписанного ключа.
- Отдельная проверка покупки сохраняет действующую лицензию; тестовые ключи не принимаются обычной активацией.
- Добавлены ссылки на оферту и условия возврата.

Продажи Pro пока не открыты. ЮKassa находится на подключении; сквозной тест в тестовом магазине и настройка чеков ещё предстоят. Подготовленный тестовый сервер пока не развёрнут.

### Проверки

Тихая установка 0.3.5.73, обновление до 0.3.5.74 и повторная установка завершились с кодом 0. Все 555 файлов установленного пакета совпали со сборкой, действующий Pro-ключ не изменился. Синтаксис удаления и очистка искусственной папки проверены; полное удаление, занятый драйвер и загрузка драйвера на чистой Windows не проверялись. Локальные проверки серверов ЮMoney и ЮKassa прошли; это не подтверждение реального платежа.

### Установка

Перед обновлением завершите приложение через «Выход» в трее. Для работы сетевого движка нужны права администратора. Бесплатные категории: YouTube + Twitch, Discord, Gaming. Для «Своих сервисов» нужна Pro-лицензия. Доступность сторонних сервисов зависит от сети и выбранной конфигурации.

```text
ZAPRET_CONTROL_0.3.5.74_Setup.exe /quiet
```
